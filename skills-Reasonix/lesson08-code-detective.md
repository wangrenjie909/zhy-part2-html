# 🚀 第8课：代码侦探——拆开作品，读懂一点点！

> ⏱️ **节奏规则（重要！）**
> 1. 每次**只展示一个阶段**的内容
> 2. 展示完后**立即停止**，等待学生回答
> 3. 学生回答后，先给予鼓励反馈，再进入下一阶段
> 4. 每个"→ 等待学生回答 ←" 标记处，必须停下来等学生输入——**宁可等 20 秒冷场，也别自己抢答**
> 5. 不要一次性展示多个阶段的内容
> 6. 一个问题只问一个孩子不够，**多让几个孩子说**：答完追问"还有谁有不一样的想法？"

学生第一次"读代码"！用侦探游戏的方式，把元素世界/烟花的代码拆开看：哪段管下落、哪段管颜色、哪段管点击。让学生发现：**代码不可怕，它就是"如果……就……"的规则清单**。

> 🕐 **本课为深化互动版，预计 90-100 分钟**：本课偏"认知"，学生动手少、动脑多——多让学生猜、让学生说，节奏放慢；若时间紧，砍挑战任务（阶段7），保留"改数字"和"升级日"。

---

## 🎯 课时目标

1. 🕵️ 第一次"读"代码：能在一段代码里找到"管什么的"部分
2. 🧠 理解代码 = 规则清单（一堆"如果……就……"）
3. 🔍 学会**读代码找 bug**：看到不对劲的代码，能猜出"哪里坏了"
4. 🎁 **亲手升级一个作品**（改一个数字/一行代码），做出自己的第 8 个作品
5. ✨ 体验"我看得懂一点了"——从"只会说"到"懂一点点"
6. 🏅 作品上主页，点亮第 8 枚徽章（进度 7/10 → 8/10）

**你：** 你已经会"指挥 AI 做作品"了。但你想不想知道——**你的作品身体里到底装着什么？** 🕵️ 就像你好奇过"机器人的肚子里是什么"，今天，我们要**拆开你的元素世界**看看！

先告诉你一个秘密：**代码一点也不可怕。** 还记得上节课你发明的法则吗？"如果岩浆碰到水，就变成石头"——**代码就是一大堆这样的"如果……就……"**！

**猜一猜（悬念）：** 你发明的法则进了电脑，会变成什么样？是变成一段"咒语"，还是变成……**一行一行像菜单一样的字**？一会儿亲眼看看！

### 阶段2：发散思维引导（约8分钟）

**你：** 先猜一猜（别怕猜错，侦探都是先猜再验证）：

1. 📜 **"你觉得代码长什么样？像故事书？像说明书？还是一堆天书？"**（追问：你觉得为什么有人怕它？）
2. 🏷️ **"你猜代码里有没有中文？还是全是英文？"**
3. 🔍 **"如果代码是一栋房子，你猜里面会有几个房间？"**（追问：管下落的房间、管颜色的房间……会有几间？）
4. 🤔 **"你觉得'读懂代码'这件事，重不重要？为什么？"**（追问：如果你能读懂说明书，是不是就不怕电器坏了？）

> 💡 **提示板**：先不揭晓答案，让学生带着好奇进入阶段3——"答案马上揭晓！"

**→ 每个问题都等待学生回答，答完追问一句"还有谁想法不一样？" ←**

### 阶段3：给代码"找房子"（约15分钟）——本课第一个重点

**你：** 现在，我们打开你的 `元素世界.html`——但先别双击！**在文件上点右键 → 打开方式 → 记事本**（或"编辑"）。看！这一大堆字，就是代码！

别怕，我们像侦探一样**按线索找房子**！我先给你看一小段（从代码里摘出来的"沙子下落"部分）：

```javascript
if (e === 1) {          // 如果这是沙子
  if (below === 0)      // 如果下面空着
    swap(s, idx(x, y + 1));  // 就往下掉一格
}
```

**看！这就是"如果……就……"！** 代码的每一行，都在说"如果怎样，就怎样"。`if` 就是"如果"的英文！

**你发现了吗？代码里还有中文！** 那些 `//` 后面的字，是程序员写给人类看的"小纸条"，叫**注释**——代码也有中文，安心了吧？

现在，跟我玩"找房子"游戏——我念线索，你来找（用 Ctrl+F 搜索，像侦探用放大镜）：

1. 🏠 **"管颜色"的房子在哪？**（提示：搜 `color`）
2. 🏠 **"管点击"的房子在哪？**（提示：搜 `mousedown`）
3. 🏠 **"管火燃烧"的房子在哪？**（提示：搜 `fire` 或 `3`）

**每找到一处，你就"读"懂了一个房间！** 🔍

**→ 等学生找到至少 2 处（找到了就大声报出来！）←**

### 阶段4：侦探任务 1——猜猜它在干什么（约10分钟）

**你：** 好！现在考考你。我给你看一段代码，**你来猜它是干什么的**：

```javascript
if (get(x, y - 1) === 3) {
  set(x, y - 1, 0);
}
```

**线索提示：** 想想你世界的法则——水灭火！🌊（第 3 个数字 3，猜猜是哪种元素？火！）

**猜猜看：这段代码说了一条什么"如果……就……"法则？**

（让学生猜。揭晓：**"如果我的上方是火（3），就把火灭掉（变成 0）"**——这是水灭火的代码！）

**你发现了吗？只要你懂"如果……就……"，你就能猜出代码在干什么！** 🎉

**追问（沉淀）：** 现在回头看——你发明的世界法则（比如"岩浆遇水变石头"），是不是也能翻译成这样的代码？大概会长什么样？

**→ 等学生试着说一句"如果…就…"翻译 ←**

---

### 阶段5：侦探任务 2——找出坏掉的代码（约15分钟）——本课第二个重点

**你：** 侦探最厉害的本领——**看到不对劲的代码，马上知道哪里坏了！**

我故意把一段代码改坏了，你来看看哪里不对劲：

```javascript
// 沙子下落（坏掉的版本！）
if (e === 1) {
  if (below === 0)
    swap(s, idx(x, y + 1));  // 这一行没问题
  if (bl === 0) swap(s, idx(x - 1, y + 1));  // 这一行也没问题
  // 咦？少了点什么……
}
```

**侦探问题：** 沙子往下掉时，能往几个方向"滑"？（下面、左下、右下……）这段代码检查了几个方向？**少了哪个？** 少了它，沙子会有什么怪行为？

**→ 等学生发现（右下 br 的检查被删了！沙子永远只往左滑，右边永远堆不成坡）←**

**验证一下：** 把这段坏代码放进你的世界试试——沙子是不是全往一边倒了？再把 `br` 那行加回去，世界就正常了！**你亲手"修"了一个 bug！** 🛠️

（老师提前在示例文件里测好"删掉 br 的效果"，确保演示真实可见）

### 阶段6：动手改一个数字（约10分钟）

**你：** 侦探毕业考试——**亲手改一行代码**！

在你的元素世界里找到这行：

```javascript
var speed = (e === 7) ? 0.45 : 1; // 岩浆更粘稠
```

（如果没有这行，就找别的数字，比如火熄灭的概率 `0.12`、沙子的下落逻辑等。）

**任务：** 把 `0.45` 改成 `1`，**保存**，刷新——看！**岩浆变得和水一样快了！** 再改回来看，岩浆又变慢了！

**你刚才是真的在"改代码"，不是在指挥 AI 改！** 你能感觉到——**改一个数字，就改变了世界。这就是程序员的快乐！** 😄

**猜一猜（悬念）：** 0.45 是"岩浆的速度"。你猜如果把火的熄灭概率 `0.12` 改成 `0.01`，世界会怎样？——先猜，一会儿挑战里试试！

**→ 等学生完成改数字实验 ←**
