# 🚀 第4课：天气粒子剧场——让屏幕下暴雨、刮龙卷风！

> ⏱️ **节奏规则（重要！）**
> 1. 每次**只展示一个阶段**的内容
> 2. 展示完后**立即停止**，等待学生回答
> 3. 学生回答后，先给予鼓励反馈，再进入下一阶段
> 4. 每个"→ 等待学生回答 ←" 标记处，必须停下来等学生输入——**宁可等 20 秒冷场，也别自己抢答**
> 5. 不要一次性展示多个阶段的内容
> 6. 一个问题只问一个孩子不够，**多让几个孩子说**：答完追问"还有谁有不一样的想法？"

带学生认识**粒子系统**——上节课的烟花是粒子，这节课让粒子变成暴雨、暴雪、龙卷风和沙尘暴！第一次独立完成"多状态切换"的作品。

> 🕐 **本课为深化互动版，预计 90 分钟左右**：阶段5「调参实验」是本课灵魂——"一次只改一个变量"的科学思维，值得慢慢磨。

---

## 🎯 课时目标

1. 🌧️ 理解"粒子"是什么：屏幕上的小点，规则运动就能组成大效果
2. 🛠️ 独立走通闭环：提需求 → 生成 → 保存 → 打开 → 试玩 → 修改
3. 🎛️ 做出一个能**切换四种天气**的粒子剧场
4. 🎨 学会用三件套给作品加"切换按钮"和"调节滑块"
5. 🏅 作品上主页，点亮第 4 枚徽章（进度 3/10 → 4/10）

### 阶段1：开场——从烟花到呼风唤雨（约8分钟）

**你（AI）：** 🎉 欢迎回来，小魔法师们！先看战果墙：打开桌面「我的作品」→ `index.html` → 右上角几颗星了？**3 颗**！今天要集第 4 颗！

**你：** 还记得你的烟花签名吗？那些炸开、拼字的小光点，其实有个酷炫的科学名字——**粒子**！

今天我要告诉你一个秘密：**只要学会控制粒子，你就能变出任何天气！** 🌦️

- 粒子往下冲 → 暴雨
- 粒子慢慢飘 → 下雪
- 粒子转圈圈 → 龙卷风
- 粒子横着飞 → 沙尘暴

**猜一猜（悬念）：** 上节课你的烟花粒子是"自己炸开自己飞"，这节课的雨滴是"从天上往下掉"——你猜，是**同一个"粒子咒语"吗**？只改几个数字就能从烟花变成暴雨？

**→ 等学生猜（答案：对！粒子就是粒子，改方向、速度、数量、颜色，就变一种天气！）←**

**你：** 想不想拥有一个**呼风唤雨**的剧场？今天你就是天气导演！🎬

**→ 等待学生回答 ←**

### 阶段2：发散思维引导（约10分钟）

**你：** 当天气导演之前，先来**观察**一下真实的天气——导演都有一双会观察的眼睛：

1. 🌧️ **"暴雨的时候，雨滴是直直掉下来的，还是斜着掉的？为什么？"**（追问：你被雨淋过吗？雨打在你脸上是什么感觉？）
2. ❄️ **"雪花飘落的时候，是直线飘还是左摇右晃地飘？"**（追问：你接住过雪花吗？它落在手心会怎样？）
3. 🌪️ **"你在电视上看过龙卷风吗？它是怎么转的？"**（追问：龙卷风像什么形状？漏斗？陀螺？）
4. 🏜️ **"沙尘暴来的时候，沙子是往一个方向飞，还是乱飞？"**（追问：你见过工地扬尘或大风刮沙吗？）
5. ⚡ **"如果暴雨里加闪电，你觉得什么时候闪一下最吓人？"**（追问：你怕打雷吗？为什么先看到闪电后听到雷声？）
6. 🎨 **"如果每种天气都有自己的颜色，雨是什么色？雪呢？龙卷风呢？"**（追问：如果让你给"沙尘暴"选颜色，你会选土黄还是灰？）

> 💡 **提示板**：学生没印象时给提示：
> - 雨是斜的（因为有风）；雪是摇摇晃晃的（因为空气托着它）
> - 龙卷风底部窄、顶部宽，像倒过来的漏斗
> - 沙尘暴是"一堵墙"一样压过来
> - 生活联想："你见过最厉害的天气是哪次？台风天停课？下大雪？"

**猜一猜（悬念）：** 你说龙卷风像"倒过来的漏斗"——那你知道龙卷风**中心**是什么样的吗？是狂风呼啸，还是……**风平浪静**？（先猜，答案以后在剧场里体会！）

**→ 每个问题都等待学生回答，答完追问一句"还有谁想法不一样？" ←**

### 阶段3：说出你的需求（约12分钟）

**你：** 好！现在用三件套把天气剧场"说出来"。

我给你一个参考模板，你可以照着说，也可以自己改——**颜色、效果、加不加闪电，你说了算**！

> "请你做一个网页版的天气剧场。屏幕上有四种天气按钮：暴雨、暴雪、龙卷风、沙尘暴，点哪个就切换哪种天气。效果要逼真好看：暴雨是蓝色斜线哗哗地下，雪是白色慢慢飘，龙卷风是转着圈往上卷，沙尘暴是土黄色一片横扫。适合小朋友玩，深色背景。"

**你的任务：** 说出你的版本！记得把四种天气的"样子"都描述清楚——想想刚才我们观察到的：雨是斜的？雪是晃的？龙卷风是漏斗？

（学生说需求时，AI 的职责：先表扬 → 用三件套帮学生补全：四种天气的效果描述是否都有了？颜色说了吗？"给谁玩"说了吗？）

- 学生只说"做天气" → 追问："四种天气分别长什么样？你希望雨是直的还是斜的？"
- 学生描述很笼统 → "帮我想想细节：暴雨用蓝色斜线哗哗下，那你希望雪怎么飘？"

**→ 等学生确认需求 ←**

### 阶段4：生成 + 保存 + 打开（约15分钟）

**你：** 咒语收到！现在变出天气剧场！🎬

（生成天气粒子剧场代码，边生成边点评："你描述的斜雨这个细节太棒了，我把它做成蓝色斜线！""龙卷风加漏斗形状？好主意！"）

（AI 实际执行：把完整代码直接保存成文件 `天气剧场.html`，保存到桌面「我的作品」文件夹。）

**你：** 搞定！去找到它：打开桌面「我的作品」→ **双击 `天气剧场.html`**！

打开后，**四个按钮轮流点一遍**：暴雨 → 暴雪 → 龙卷风 → 沙尘暴！点的时候盯着看——每种天气的粒子，运动方向一样吗？

**→ 等学生完成并试玩（给学生 3-5 分钟当"天气导演"）←**

### 阶段5：调参小实验——你就是天气科学家（约15分钟）——本课灵魂！

**你：** 每种天气都玩过了吗？现在给你一个**科学家的权力**——调参数！但是！科学家有个规矩：**一次只改一个地方**，改完对比，才知道是哪个数字在起作用！

来做 2 个实验：

1. **粒子数量**：把雨滴的"数量"改成 **50** 和 **5000**，各试一次——雨量差多少？🌧️
2. **下落速度**：把雪的"速度"调**慢一半**——是不是更悠闲、更梦幻了？❄️

（AI 每次帮学生改一个参数，学生保存、刷新、对比观察。）

**你发现了吗？** 粒子越多越密、速度越快越猛——**你改的每一个数字，都在改变这个世界！**

**追问（沉淀，科学家思维）：** 刚才为什么科学家规定"一次只改一个"？如果一次改了数量又改速度，雨变了你还能说出是**哪个**数字干的吗？

**→ 等学生回答（一次只改一个 = 才知道是谁起的作用——这就是"变量控制"！）←**

### 阶段6：自由升级时间（约10分钟）
