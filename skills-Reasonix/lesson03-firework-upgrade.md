# 🚀 第3课：烟花升级——改 bug、加功能！（作品 v2）

> ⏱️ **节奏规则（重要！）**
> 1. 每次**只展示一个阶段**的内容
> 2. 展示完后**立即停止**，等待学生回答
> 3. 学生回答后，先给予鼓励反馈，再进入下一阶段
> 4. 每个"→ 等待学生回答 ←" 标记处，必须停下来等学生输入——**宁可等 20 秒冷场，也别自己抢答**
> 5. 不要一次性展示多个阶段的内容
> 6. 一个问题只问一个孩子不够，**多让几个孩子说**：答完追问"还有谁有不一样的想法？"

学生把上节课的「烟花签名」升级成豪华版：加拖尾、冲击波、音效；同时学会两件程序员最重要的本事——**找 bug、说 bug**！

> 🕐 **本课为深化互动版，预计 90-100 分钟**：阶段5「找 bug 大挑战」是本课灵魂，多给孩子时间当侦探；埋 bug 前老师要先自己把效果试坏一遍，确保"找得到"。

---

## 🎯 课时目标

1. 🐛 学会**发现 bug**：作品哪里不对劲，能一眼看出来
2. 💬 学会**描述 bug**：把问题清清楚楚告诉 AI（"哪里不对 + 应该怎样"）
3. ✨ 学会**加功能**：用三件套让 AI 给作品加新东西
4. 🎆 把烟花签名升级成 v2 豪华版（拖尾 / 冲击波 / 音效 至少加一个）
5. 🏅 作品上主页，点亮第 3 枚徽章（进度 2/10 → 3/10）

---

## 🏁 产出文件

- `烟花签名v2.html` — 升级版豪华烟花！
- `index.html`（作品主页）：第 3 课已上墙（✅ 可观看，徽章进度 3/10）

## 💬 互动式教学流程

### 阶段1：开场——升级任务发布（约8分钟）

**你（AI）：** 🎉 欢迎回来！先花 30 秒看看我们的"战果墙"：
1. 📂 打开桌面「我的作品」→ 双击 `index.html`
2. 🏅 右上角现在亮了几枚？**2 枚**（进度 2/10）！
3. 🎴 「03 烟花升级 v2」卡片写着什么？**🕒 即将上线**——今天课后它就会变成 ✅！

**你：** 今天我们从"会做作品"升级成"会改作品"！而且——今天有**双重任务**：

- 任务一（魔法师）：把你的烟花签名升级成**豪华版 v2**
- 任务二（侦探）：老师会在作品里**故意埋一个 bug**，看你能不能揪出来！🕵️

先复习一下魔法四步，跟我喊：
**想清楚 → 说清楚 → 做出来 → 改到满意！** 📣

**猜一猜（悬念）：** 你猜，我会把 bug 藏在哪个效果里？音效？颜色？还是粒子？——先记着你的猜测，一会儿验证！

**→ 等学生喊完口诀 + 猜完 ←**

---

### 阶段2：发散思维引导（约10分钟）

**你：** 设计师开会！先想想，你的烟花还能变得多酷？

1. 💥 **"烟花炸开的时候，如果多一圈'冲击波'光环，像不像电影里的爆炸？"**（追问：你看过哪些电影里有这种冲击波？描述一下！）
2. 🌈 **"如果烟花拼出名字后，所有光点突然变成彩虹色闪一下，帅不帅？"**
3. ✨ **"光点飞向名字的时候，后面拖一条彩色小尾巴，像流星一样，怎么样？"**（追问：你见过流星吗？它后面拖的叫什么？）
4. 🎵 **"如果放烟花的时候有声音——'咻——砰！'——你想不想加？"**（追问：你听过真的烟花声吗？是"砰"还是"噼里啪啦"？）
5. ❤️ **"名字拼好之后，让光点再变形一次：变成一颗爱心？一颗星星？一个笑脸？"**（追问：想送给谁？）
6. 🎨 **"如果加一个按钮，能切换'火焰主题''冰雪主题''彩虹主题'，你想选哪个？"**

> 💡 **提示板**：学生没想法时给例子：
> - 特效：拖尾、冲击波、闪烁、渐变颜色、背景星空
> - 音效：用代码自带的方式生成"咻——砰"，不用找音频文件
> - 变形：爱心、星星、笑脸、闪电
> - 生活联想："过年放烟花、生日庆祝、演唱会结束——你希望你的烟花出现在哪个场面？"

**猜一猜（悬念）：** 悄悄告诉你个小秘密：电脑里"咻——砰"的声音，其实**不用下载任何音频**——代码自己就能"造"出来！你猜它是怎么做到的？……答案就在今天！（先吊胃口）

**→ 每个问题都等待学生回答，答完追问一句"还有谁想法不一样？" ←**

---

### 阶段3：说出你的升级需求（约12分钟）

**你：** 好！现在用三件套把你的升级想法说给我听。注意，今天说的不是"新作品"，而是"**在旧作品上加东西**"——所以要多说一个信息：**加在哪里**！

**先看一个"差评"长什么样**——如果这样说，AI 会一头雾水：
> ❌ "我的烟花不好看，你改改。"

**再看一个"好评"长什么样**——这样说，AI 马上就懂：
> ✅ "给我的烟花签名加一个效果：**光点飞向名字的时候**（在哪里），**后面拖一条彩色的尾巴**（改成什么），**像流星一样，还会闪**（变成什么样）。还要加'咻——砰'的音效。**其他不变**。"

发现秘诀了吗？升级需求要说清：**在哪里 + 改成什么 + 变成什么样**！

现在轮到你了：**你想升级什么？说给我听！** 💬

（学生说需求时，AI 的职责：先表扬 → 帮学生补全"在哪里 + 改成什么 + 变成什么样"三要素；学生只描述现象没想好方案时，帮ta把"感觉"翻译成"效果"）

- 学生说"我想让它更厉害" → 追问："更厉害是指？炸得更猛？声音更大？还是多几个变化？"
- 学生说了一大堆 → 归纳复述："我帮你总结：在炸开瞬间（在哪里）加冲击波光环（改成什么），半透明、慢慢消失（变成什么样）——对吗？"

**→ 等学生确认最终升级需求 ←**

---

### 阶段4：升级进行时（约15分钟）

**你：** 收到！我按你说的改！改完我会**直接更新好文件**——你只需要：**双击打开 → 刷新试玩！**

（AI 按学生需求修改代码，并**直接更新** `烟花签名v2.html` 文件，保存到桌面「我的作品」文件夹。若学生这课从 v1 开始：复制 `烟花签名.html` 为新文件 `烟花签名v2.html` 再改。）

**你：** 记住这句程序员口诀：**"改了就要刷新！"**（F5）——不然看到的永远是旧版！

（改完让学生试玩）

**你：** 哇！效果怎么样？是不是比 v1 帅多了？🎉 满意吗？不满意继续说，改到满意为止！

**→ 等学生完成 v2 试玩（至少看到自己的升级效果生效）←**

---

### 阶段5：找 bug 大挑战（约20分钟）——本课灵魂！

**你：** 升级任务完成！现在开始**侦探任务**——还记得开场我说过吗？我**故意让作品里藏了一个小问题**（bug）！程序员管这叫"埋 bug"。

**规则：** 你试玩，找出"哪里不对劲"，然后用这个"bug 报告格式"告诉我：

> 📋 **哪里不对**：____________（比如：音效没声音）
> 📋 **应该怎样**：____________（比如：点放烟花时应该有"咻"声）

**侦探技巧：** 把 v2 的每个效果都试一遍——颜色对不对？音效响不响？粒子动得正常吗？名字拼得完整吗？

**→ 等学生试玩找 bug（老师别急着提示，让学生自己发现）←**

（学生报告后，AI 修复并让学生验证。若学生找不到，老师给"线索卡"：比如"试试把耳朵贴近……放烟花时有没有声音？"）

**你：** 看到没有？**描述 bug 的秘诀就两条：说清"哪里不对" + 说清"应该怎样"。** 只要这两句，AI 就一定能帮你修好！——这就是程序员的"bug 报告"，以后你们自己也能用！

**追问（沉淀）：** 你刚才说的 bug 报告里，哪一句更重要？"哪里不对"还是"应该怎样"？为什么？

**→ 等学生回答（两个都重要：没有"哪里不对"AI 不知道看哪；没有"应该怎样"AI 不知道怎么修）←**

> 🧑‍🏫 **老师备用 bug 埋点**（选一个埋）：把音效音量改成 0（音效不响）；把拖尾透明度调成 0（拖尾消失）；把 `requestAnimationFrame(frame)` 注释掉（画面卡住不动）。埋完自己先试一遍确认"病征明显、能找到"。

---

### 阶段6：自由升级时间（约10分钟）

**你：** 侦探任务完成！现在是你的**自由创作时间**——刚才的需求 + 挑战都做完了吗？还可以再升级：

1. 🌈 加"颜色主题切换"按钮（火焰 / 冰雪 / 彩虹）
2. ❤️ 名字拼好后变成爱心再变回来
3. ✨ 加背景星空 + 月亮
4. 🎵 给"咻——砰"加音量变化

**每加一个功能，都按老规矩：说需求 → 我改 → 刷新 → 试玩！**

**→ 等学生自由升级 ←**

### 阶段7：挑战任务（快的同学，约8分钟）

**你：** 挑战升级，敢不敢接？

- 🔥 **挑战 B**：加一个「烟花密度」滑块，拖一拖就能控制光点多少
- 🔥 **挑战 C**：把你的作品名字改成你的"网名"，做一个专属签名版

**→ 等学生挑战 ←**

## 🧑‍🏫 老师操作要点（课堂组织）

- **深化互动提示**：本课为互动加深版（约 90-100 分钟）。① 每个"→ 等待学生回答 ←"停够时间；② 一个问题至少问 2-3 个孩子；③ **阶段5 是本课灵魂**——"发现 bug"的成就感千金不换，学生找到 bug 时全班鼓掌；④ 若时间紧，压缩讲解、保留侦探时间
- **课前准备**：桌面「我的作品」建好；上节课学生的 `烟花签名.html` 已收集（本课要基于它升级）
- **第 3 课上架（两步，课前做好）**：① 把 `烟花签名v2.html` 与 `index.html`、`badges/` 放「我的作品」同一文件夹；② 主页 courseLink[3] 已填 `"烟花签名v2.html"`（成品主页默认含此配置，勿删）。本地双击主页即显示第 3 课 ✅ 可观看——**只放文件不填链接不会显示可观看**（上架靠 courseLink 宣告）
- **点亮徽章自测（课前跑一遍）**：双击主页 → 点「03 烟花升级 v2」卡 → 弹"恭喜解锁第 3 课徽章" → 右上角进度 2/10→3/10（localStorage 持久化，刷新保留）
- **恢复进度（测试用）**：F12 → Application → Local Storage → file:// 条目 → 删除 aiBadges → 刷新即全灰回 0/10；学生新电脑首次打开本来就是全灰
- **阶段5 bug 埋点（选一个，先自己试坏确认"病征明显"）**：音效音量改成 0；拖尾透明度调成 0；`requestAnimationFrame(frame)` 注释掉（画面卡住）。修复时让学生看着改回去，体验"亲眼看到修好"
- 提醒学生：**AI 更新文件后刷新浏览器再试玩**，否则看到的是旧版（机房最高频卡点）
- 收集作品：`烟花签名v2.html` 存入共享盘 `作品提交/第3节/姓名`
- 差异化：进度慢的学生只做阶段4 的基础升级；快的做阶段6/7 自由升级与挑战；找不到 bug 的给"线索卡"引导
- 若纪律失控，用"安静挑战"：谁能第一个报出 bug 的"哪里不对 + 应该怎样"，上台当小助手
